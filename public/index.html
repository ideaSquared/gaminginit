    Seeding

    How an empty server becomes a full match.

    Seeding is playing on the server while it has few or no players, so that it fills up. Most players skip a server that looks empty, so it takes a few of us to get it going. Once it reaches 20 players it goes live and full matches start.

    1. Empty

      0 players

      Nobody is on. The first player to join starts the seed.

    2. Seeding

      1–19 players

      The bot posts in Discord to bring more people in. Play as normal while it fills up.

    3. Live

      20+ players

      Full matches. If players leave and it stays low for a few minutes, the bot asks for help to keep it going.

    How to help

    • Join when the bot posts a seeding alert in our Discord, or when the server card above says Seeding.
    • Stay until it goes live. The server card shows how many more players it needs; the line on its bar marks the live point.
    • Bring friends. A squad fills the server faster than one player.

    When the server goes live, the bot names the 3 players who seeded longest in Discord.

    What seeding earns

    • A reserved slot lets you skip the queue when the server is full.
    • Seed enough again before your slot ends and you keep it.
    • Slots start and end at the server’s next restart, usually its daily one.
